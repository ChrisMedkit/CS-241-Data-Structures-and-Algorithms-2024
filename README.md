# CS-244 Data Structures (C++)

Coursework from **2024 Summer** at **UW-Stout**.

C++ programs from a data structures course: stacks, queues, singly and
doubly linked lists, a custom linked list with iterators, file input and
output, and class design with the "rule of three" (copy constructor,
assignment operator, destructor).

## Project details

### MessageEncoder
Reads a multi-line message from the keyboard (press Enter twice to finish),
reverses every other word on each line, then uses a stack to write the lines
out in reverse order. The encoded result is printed and saved to
`encoded.txt`.

### PlayerRecords
Stores player data (name, rating, team, jersey number, goals scored) in a
text file, reads it back, sorts players by goals scored, and prints a
formatted report. Expects `players.txt` in the working directory, in groups
of five lines per player.

### ArrayStack
A generic stack that starts at 10 slots, grows by 25% when full, and shrinks
when it becomes less than half full. Includes a copy constructor, assignment
operator, and destructor.

### ArrayQueue
A generic queue stored in a circular array. `front` and `last` wrap around
using modular arithmetic, and the array grows by 25% when full. Includes
`printQueue()` and a stream insertion operator.

### LinkedLists
- **`SLinkedList.cpp`:** singly linked list with head and tail pointers,
  copy constructor, assignment operator, a count of how many times a value
  appears, and an intersection operator (`*`).
- **`DLinkedList.cpp`:** doubly linked list with header and trailer
  sentinel nodes, plus a test driver that checks copying and assignment.

### VehicleInventory
An inventory of vehicles stored in a custom doubly linked list
(`NodeList<T>`) with iterator support. Each `Vehicle` has its own list of
extra features. Supports printing all, available, and reserved vehicles,
reserving and returning vehicles (with exceptions for invalid or repeated
requests), searching by seat count, and saving to a file.
`vehicles.txt` is sample input data.

**Status: work in progress.** Sorting, ID checking, and loading from
`vehicles.txt` are not implemented yet.

### Battleship
A one-player console game on a 6x6 grid. The program places six ships at
random, and you enter `x y` coordinates until every ship is sunk. Results
are reported as Miss, Hit and sunk, or Already sunk.

## Compiler notes

- The code was written in **Visual Studio**. `ArrayQueue` and `DLinkedList`
  use a template `friend` declaration that reuses the class's own template
  parameter name. Visual Studio accepts this, but GCC and Clang reject it.
  Renaming the friend's parameter (for example `template <class U>`) fixes it.
- Text files created on Windows use CRLF line endings. A `.gitattributes`
  file in this repo normalizes them.
